# Loop Engineering pour Openfunds

Loop Engineering transforme chaque intervention en boucle contrôlée :

```text
OBSERVE → FRAME → PLAN → CHANGE → VERIFY → LEARN → HANDOFF
```

Chaque boucle possède un `LOOP_ID`, une tâche `OF-*`, un HEAD de départ, une
baseline, des critères d’acceptation, une allowlist de fichiers, des preuves,
des conditions d’arrêt et une prochaine action unique.

La boucle ne remplace pas Git, les ADR, les tests ou les documents canoniques ;
elle les relie afin de réduire la dérive entre conversation, dépôt, base,
workflows et production.
