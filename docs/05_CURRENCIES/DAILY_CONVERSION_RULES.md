# DAILY CONVERSION RULES

## OBJECTIVE

CREATE AUDITABLE DAILY LOCAL, EUR AND USD SERIES FOR EVERY CONVERTIBLE NATIONAL OBSERVATION WITHOUT ALTERING THE NATIVE SOURCE VALUE.

## CANONICAL LAYERS

1. NATIVE OBSERVATION IN SOURCE CURRENCY.
2. FX OBSERVATION USED FOR THE ECONOMIC DATE.
3. CONVERTED EUR OBSERVATION.
4. CONVERTED USD OBSERVATION.

THE NATIVE OBSERVATION IS NEVER OVERWRITTEN.

## QUOTE CONVENTION

ALL CANONICAL PAIRS USE:

`1 UNIT OF SOURCE CURRENCY = X UNITS OF TARGET CURRENCY`

EXAMPLE:

`MAD_EUR = NUMBER OF EUR FOR 1 MAD`

THE CONVERTED VALUE IS:

`TARGET_VALUE = SOURCE_VALUE * FX_RATE`

## TARGET CURRENCIES

- EUR
- USD

## DATA TO CONVERT

- NAV
- AUM
- DIVIDENDS
- PRICES
- MARKET CAPITALISATION
- OUTSTANDING AMOUNTS
- MONETARY FLOWS
- COUPONS AND CASH FLOWS
- INDEX LEVELS WHEN THE INDEX METHODOLOGY REQUIRES A CURRENCY VERSION

## DATA NOT DIRECTLY CONVERTED

- INTEREST RATES
- INFLATION RATES
- GROWTH RATES
- RATIOS
- VOLATILITY
- SHARPE
- BETA
- PERCENTILES

THESE ARE EITHER DIMENSIONLESS OR RECALCULATED FROM THE CORRECT CURRENCY SERIES.

## DATE RULE

THE FX OBSERVATION MUST MATCH THE ECONOMIC DATE OF THE SOURCE OBSERVATION.

IF THE DIRECT FX RATE IS UNAVAILABLE:

1. USE AN APPROVED DIRECT OFFICIAL RATE IF AVAILABLE.
2. OTHERWISE USE AN APPROVED TRIANGULATION PATH.
3. OTHERWISE MARK THE CONVERSION MISSING.

NO SILENT CARRY FORWARD IS ALLOWED WITHOUT AN EXPLICIT VERSIONED FALLBACK RULE.

## TRIANGULATION

A TRIANGULATED RATE MUST STORE:

- EACH INPUT FX OBSERVATION ID;
- TRIANGULATION CURRENCY;
- CALCULATION FORMULA;
- METHODOLOGY VERSION;
- QUALITY STATUS.

## REGIONAL AND AFRICA USE

REGIONAL AND AFRICA PERFORMANCES, METRICS, WTI SERIES AND RANKINGS ARE RECALCULATED FROM FUND-LEVEL EUR OR USD SERIES.

THEY ARE NOT COPIED FROM LOCAL-CURRENCY NATIONAL RESULTS.

## REQUIRED LINEAGE

EVERY CONVERTED OBSERVATION MUST STORE:

- SOURCE OBSERVATION ID;
- SOURCE CURRENCY;
- TARGET CURRENCY;
- FX OBSERVATION ID OR TRIANGULATION INPUT IDS;
- FX RATE;
- ECONOMIC DATE;
- CONVERSION METHOD;
- METHODOLOGY VERSION;
- QUALITY STATUS;
- CALCULATION RUN ID.

## QUALITY STATES

- OBSERVED_DIRECT
- CALCULATED_TRIANGULATED
- CARRIED_FORWARD_APPROVED
- PROVISIONAL
- VALIDATED
- MISSING
- REJECTED

## NON REGRESSION RULES

1. LOCAL VALUES REMAIN THE PRIMARY NATIVE SOURCE SERIES.
2. EUR AND USD ARE EXPLICIT DERIVED SERIES, NOT DISPLAY-ONLY CONVERSIONS.
3. REGIONAL AND AFRICA ANALYTICS USE THE DERIVED FUND-LEVEL SERIES.
4. NO RATE, DATE OR SOURCE IS INVENTED.
5. EVERY REVISION CREATES A TRACEABLE NEW CALCULATION RESULT.
