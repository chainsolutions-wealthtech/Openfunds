# Plan de validation produit

Pour chaque capacité : hypothèse, population, scénario, données de test, métriques, seuils, risques, preuve et décision. La validation combine tests techniques, revue métier, comparaison aux sources et contrôle de provenance. Les pilotes FX sont `COLLECTION_TESTED`; les historiques, le modèle fonds final et les produits analytiques restent non validés.
