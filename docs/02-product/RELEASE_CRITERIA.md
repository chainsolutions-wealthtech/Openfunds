# Critères de release

Une release exige : périmètre versionné, critères acceptés, tests applicables verts, migrations et rollback vérifiés, documentation cohérente, aucun secret, risques résiduels approuvés, observabilité et handoff. Les statuts `STRUCTURE_PREFILLED`, `COLLECTION_TESTED` ou `IMPLEMENTED` ne suffisent pas à annoncer une capacité production. Aucun release process n’est actif dans la boucle OF-DOC-003.
