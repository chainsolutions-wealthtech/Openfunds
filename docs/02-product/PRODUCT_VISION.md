# Vision produit

Openfunds vise une source panafricaine canonique, historisée et traçable pour les fonds, marchés et institutions, avec openfunds comme couche d’échange. La vision inclut comparaison, reporting, API et analyses reproductibles, mais n’autorise aucune revendication d’historique complet ou de calcul actif avant preuve. Les références sont `README.md`, `PROJECT_BRIEF.md` et `SOURCE_OF_TRUTH.md`.
