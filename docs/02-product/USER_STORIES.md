# User stories

Format : « En tant que [rôle], je veux [capacité], afin de [valeur] », avec source, hypothèses, données, règles, critères d’acceptation, sécurité et preuve. Exemples : retrouver l’identité historique d’un fonds ; comparer des classes de parts ; tracer une VL jusqu’à sa cellule source ; exporter un mapping openfunds. Les stories restent à valider avant développement.
