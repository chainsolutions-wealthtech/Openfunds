# Matrice d’approbation humaine

| Action | Approbation |
|---|---|
| lecture/analyse | non |
| documentation dans allowlist | instruction explicite |
| code, SQL, données, workflow | tâche technique + revue |
| nouvelle branche ou PR | autorisation explicite |
| merge, retarget, suppression | mainteneur explicite |
| secret, production, migration destructive | propriétaire + sécurité/ops |
| décision ADR | responsable désigné |
