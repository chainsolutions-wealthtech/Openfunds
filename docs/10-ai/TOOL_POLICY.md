# Politique des outils

Utiliser uniquement les outils réellement disponibles et nécessaires. Vérifier cible et paramètres avant toute écriture, privilégier lecture puis action minimale, ne jamais exposer secrets, ne pas simuler une exécution et conserver la sortie utile. Les opérations Git destructives ou production exigent une autorisation distincte. Toute limitation d’outil est inscrite dans le rapport.
