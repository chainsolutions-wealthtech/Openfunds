# Quality gates

Gates minimaux : diff propre, aucune suppression imprévue, secrets absents, format valide, tests ciblés et globaux applicables, migrations idempotentes, documentation et statut cohérents, CI vérifiée, rollback disponible. Pour les données : source, date, unité, devise, provenance et statut. Un gate non exécuté est `NOT_VERIFIED`, jamais `PASS`.
