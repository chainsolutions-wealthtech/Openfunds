# Protocole de validation

1. identifier autorité et critères ; 2. capturer état initial ; 3. exécuter contrôle reproductible ; 4. conserver sortie et commit ; 5. comparer aux seuils ; 6. classifier PASS/FAIL/PARTIAL/NOT_RUN ; 7. documenter limite et prochaine action. Pour les données, vérifier type, unité, devise, date, source, hash, lignée et maturité.
