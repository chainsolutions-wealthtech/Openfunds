# Checklist de revue d’architecture

- [ ] décision reliée à une tâche et un ADR
- [ ] sources de vérité explicites
- [ ] couches raw/normalisé/validé/canonique/analytique/API/UI séparées
- [ ] temporalité et provenance couvertes
- [ ] compatibilité et migration non destructives
- [ ] sécurité, performances et observabilité évaluées
- [ ] rollback et tests définis
- [ ] aucun statut de production sans preuve
