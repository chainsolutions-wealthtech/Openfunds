# PROVIDER SERIES AND COLLECTION SPECIFICATION MODEL

## 1. OBJECTIF

CE MODELE TRANSFORME UN MAPPING PAYS OU ZONE X INDICATEUR X SOURCE EN OBJET TECHNIQUEMENT COLLECTABLE ET AUDITABLE.

LA CHAINE EST :

PAYS OU ZONE
→ INDICATEUR CANONIQUE
→ ORGANISATION
→ ENDPOINT
→ SERIE FOURNISSEUR
→ SPECIFICATION DE COLLECTE
→ EXECUTION DE COLLECTE
→ ARTEFACT BRUT
→ EXTRACTION
→ VALIDATION
→ OBSERVATION CANONIQUE
→ INDICE / WTI / WTI BENCH / METRIQUE

## 2. DISTINCTIONS OBLIGATOIRES

- UN INDICATEUR CANONIQUE N EST PAS UNE SERIE FOURNISSEUR.
- UNE SERIE FOURNISSEUR N EST PAS UN ENDPOINT.
- UN ENDPOINT N EST PAS UNE SPECIFICATION DE COLLECTE.
- UNE SPECIFICATION DE COLLECTE N EST PAS UNE EXECUTION.
- UNE EXECUTION N EST PAS UN ARTEFACT BRUT.
- UNE OBSERVATION CANONIQUE NE DOIT JAMAIS ECRASER L ARTEFACT BRUT.

## 3. PROVIDER_SERIES

UNE SERIE FOURNISSEUR CONSERVE :

- PROVIDER_SERIES_ID ;
- MAPPING_CODE ;
- ORGANIZATION_CODE ;
- ENDPOINT_CODE ;
- CANONICAL_INDICATOR_CODE ;
- CODE NATIF DE SERIE ;
- NOM NATIF DE SERIE ;
- URL DIRECTE DE SERIE ;
- FREQUENCE NATIVE ;
- UNITE NATIVE ;
- DEVISE NATIVE ;
- DATE DE DEBUT ET DE FIN ;
- POLITIQUE DE REVISION ;
- STATUT D HISTORIQUE ;
- STATUT DE VALIDATION.

LES CODES OU NOMS NATIFS NON VERIFIES RESTENT VIDES. ILS NE SONT PAS INVENTES.

## 4. COLLECTION_SPECIFICATION

UNE SPECIFICATION DE COLLECTE DEFINIT COMMENT RECUPERER ET INTERPRETER LA SERIE :

- METHODE DE COLLECTE ;
- TYPE D ENDPOINT ;
- METHODE HTTP ;
- REGLE DE DECOUVERTE ;
- MOTIF DE FICHIER ;
- REGLE DE FEUILLE ;
- SELECTEUR HTML OU TABLE ;
- REGLE D EXTRACTION DE DATE ;
- REGLE D EXTRACTION DE VALEUR ;
- REGLE DE PARSING NUMERIQUE ;
- REGLE DE DEVISE ;
- FREQUENCE DE VERIFICATION ;
- RETARD DE PUBLICATION ATTENDU ;
- CLE DE DEDOUBLONNAGE ;
- TRAITEMENT DES REVISIONS ;
- CONSERVATION DE L ARTEFACT BRUT ;
- HASH SHA256 ;
- VERSION DU PARSER ;
- POLITIQUE DE RETRY ;
- PROFIL DE CONTROLES QUALITE.

## 5. REGLES DE NON REGRESSION

1. AUCUN CODE DE SERIE, URL, SELECTEUR, NOM DE FEUILLE OU DATE DE DEBUT N EST INVENTE.
2. TOUT ARTEFACT BRUT EST CONSERVE AVEC HASH ET DATE DE COLLECTE.
3. TOUTES LES REVISIONS ET VINTAGES SONT CONSERVES.
4. LES SERIES DE ZONE UEMOA ET CEMAC NE SONT PAS DUPLIQUEES PHYSIQUEMENT POUR CHAQUE PAYS.
5. LES VALEURS LOCALES RESTENT NATIVES ; LES CONVERSIONS EUR ET USD SONT DES OBSERVATIONS DERIVEES AVEC LINEAGE FX.
6. LES INDICES REGIONAUX ET AFRICA SONT RECALCULES A PARTIR DES SERIES CONVERTIES.
7. WTI ET WTI BENCH RESTENT DEUX PRODUITS DISTINCTS.
8. UNE SPECIFICATION GENERIQUE NE PEUT PAS ETRE EXECUTEE TANT QU UNE SPECIFICATION PRECISE PAR SERIE N A PAS ETE VALIDEE.

## 6. HISTORISATION

LE MODELE CONSERVE :

- LA PERIODE DE VALIDITE DE LA SERIE FOURNISSEUR ;
- LA PERIODE DE VALIDITE DE LA SPECIFICATION ;
- CHAQUE EXECUTION DE COLLECTE ;
- CHAQUE ARTEFACT BRUT ;
- LES VERSIONS DU PARSER ;
- LES VALEURS INITIALES ET REVISEES ;
- LES CORRECTIONS ET CONFLITS.

## 7. STATUTS DE PROGRESSION

- SOURCE_IDENTIFIED
- SERIES_IDENTIFIED
- SPECIFICATION_REQUIRED
- SPECIFICATION_DRAFTED
- COLLECTION_TESTED
- PARTIAL_HISTORY_LOADED
- COMPLETE_HISTORY_LOADED
- NOT_PUBLISHED
- NOT_APPLICABLE
- DISCONTINUED
- REPLACED

## 8. PROCHAINE ETAPE

POUR CHAQUE SERIE PRIORITAIRE :

1. VERIFIER L URL ET LE CODE EXACTS ;
2. DETERMINER LE FORMAT ET LA PROFONDEUR HISTORIQUE ;
3. REDIGER LA SPECIFICATION PRECISE ;
4. TESTER UNE COLLECTE ;
5. CONSERVER L ARTEFACT BRUT ;
6. VALIDER LES REGLES DE PARSING ;
7. CHARGER UN PREMIER HISTORIQUE ;
8. EXECUTER LES CONTROLES QUALITE ;
9. PUBLIER LES OBSERVATIONS CANONIQUES ;
10. RACCORDER LES SERIES AUX INDICES ET BENCHMARKS.
