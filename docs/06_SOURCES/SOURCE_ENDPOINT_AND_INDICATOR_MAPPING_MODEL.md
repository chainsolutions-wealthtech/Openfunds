# SOURCE ENDPOINT AND INDICATOR MAPPING MODEL

## OBJECTIF

RELIER CHAQUE INDICATEUR CANONIQUE A L ORGANISATION, AU ROLE INSTITUTIONNEL, A L ENDPOINT ET A LA SERIE FOURNISSEUR QUI LE PUBLIE.

## CHAINE CANONIQUE

PAYS OU ZONE
→ ORGANISATION
→ ROLE
→ ENDPOINT
→ SERIE FOURNISSEUR
→ INDICATEUR CANONIQUE
→ OBSERVATION
→ UTILISATION DANS INDICE, WTI BENCH, METRIQUE OU CONVERSION FX

## PRINCIPES DE NON REGRESSION

1. LE PAYS RESTE LA RACINE DE CLASSIFICATION NATIONALE DES FONDS.
2. UNE ZONE COMME UEMOA OU CEMAC PEUT PORTER UNE SERIE COMMUNE SANS REMPLACER LES PAYS MEMBRES.
3. UNE ORGANISATION EST DISTINCTE DE SES ENDPOINTS.
4. UN ENDPOINT EST DISTINCT D UNE SERIE FOURNISSEUR.
5. UNE SERIE FOURNISSEUR EST MAPPEE VERS UNE DEFINITION CANONIQUE.
6. LES URL, CODES DE SERIES ET HISTORIQUES NON VERIFIES RESTENT VIDES OU PENDING.
7. AUCUNE SERIE N EST DUPLIQUEE PHYSIQUEMENT POUR CHAQUE PAYS LORSQU ELLE EST PORTEE PAR UNE ZONE COMMUNE.
8. LES SOURCES PRIMAIRES ET SECONDAIRES SONT VERSIONNEES ET PRIORISEES.

## PREMIER PEUPLEMENT

LE PREMIER PEUPLEMENT COUVRE UNIQUEMENT LES PERIMETRES DEJA PRESENTS DANS LE SOCLE :

- UEMOA / BCEAO / BRVM ;
- CEMAC / BEAC / BVMAC ;
- AFRIQUE_DU_SUD / SARB / JSE.

LES MAPPINGS CREES PORTENT SUR :

- TAUX DIRECTEURS ;
- TAUX INTERBANCAIRES ;
- FX LOCAL VERS EUR ET USD ;
- INDICE ACTIONS ALL SHARE ;
- INDICE ACTIONS TOTAL RETURN LORSQUE SA DISPONIBILITE DOIT ETRE VERIFIEE.

## PROCHAINE ETAPE

1. VERIFIER LES URL OFFICIELLES.
2. IDENTIFIER LES CODES ET NOMS EXACTS DES SERIES.
3. AJOUTER LES ORGANISATIONS NATIONALES DES 54 PAYS.
4. ETENDRE LES MAPPINGS AUX DOMAINES D03, D04, D05, D06, D08, D10, D11, D12 ET D16.
5. TESTER LES COLLECTEURS.
6. CHARGER LES HISTORIQUES.
7. LIER CHAQUE OBSERVATION A SON ENDPOINT, SA SERIE ET SON ARTEFACT SOURCE.
