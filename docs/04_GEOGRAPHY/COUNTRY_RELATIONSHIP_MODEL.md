# COUNTRY RELATIONSHIP MODEL

## 1. OBJECTIF

CE DOCUMENT DEFINIT LES RELATIONS A CONSERVER POUR CHAQUE PAYS AVANT LA GENERATION DE LA TAXONOMIE DES FONDS.

LE MODELE DOIT PERMETTRE, A PARTIR D UN PAYS, DE RETROUVER AUTOMATIQUEMENT :

- SA REGION GEOGRAPHIQUE ;
- LE CONTINENT AFRICA ;
- SA DEVISE LOCALE ;
- SA ZONE MONETAIRE EVENTUELLE ;
- SA BANQUE CENTRALE ;
- SA BOURSE NATIONALE OU COMMUNE ;
- SON PERIMETRE DE MARCHE ;
- LES SOURCES ET INDICATEURS A UTILISER ;
- LES FUTURES CATEGORIES NATIONALES, REGIONALES ET AFRICA.

## 2. REGIONS GEOGRAPHIQUES RETENUES

- AFRICA_NORD
- AFRICA_CENTRALE
- AFRICA_EST
- AFRICA_OUEST
- AFRICA_AUSTRALE

CHAQUE REGION A POUR PARENT :

- AFRICA

## 3. PRINCIPES DE NON REGRESSION

1. LE PAYS RESTE TOUJOURS L ENTITE DE DOMICILIATION DU FONDS.
2. LA REGION GEOGRAPHIQUE NE DOIT PAS ETRE REMPLACEE PAR UNE ZONE MONETAIRE.
3. UEMOA ET CEMAC SONT DES PERIMETRES DE MARCHE ET MONETAIRES COMMUNS.
4. LES PAYS UEMOA UTILISENT LES REFERENCES COMMUNES BCEAO ET BRVM LORSQUE LA DONNEE EST DE NATURE MONETAIRE OU BOURSIERE COMMUNE.
5. LES PAYS CEMAC UTILISENT LES REFERENCES COMMUNES BEAC ET BVMAC LORSQUE LA DONNEE EST DE NATURE MONETAIRE OU BOURSIERE COMMUNE.
6. LES SERIES COMMUNES NE DOIVENT PAS ETRE DUPLIQUEES PHYSIQUEMENT POUR CHAQUE PAYS.
7. UNE CATEGORIE NATIONALE PEUT POINTER VERS UNE SERIE DE MARCHE PORTEE PAR UNE ZONE COMMUNE.
8. LES RELATIONS SONT HISTORISEES AVEC VALID_FROM ET VALID_TO.
9. LES NOMS TECHNIQUES SONT EN MAJUSCULES ET SANS ACCENT.
10. LES LIBELLES HUMAINS PEUVENT CONSERVER LES ACCENTS DANS LES CHAMPS D AFFICHAGE.

## 4. TYPES DE RELATIONS

### 4.1 GEOGRAPHIE

- BELONGS_TO_REGION
- BELONGS_TO_CONTINENT

EXEMPLE :

COTE_D_IVOIRE
- BELONGS_TO_REGION -> AFRICA_OUEST
- BELONGS_TO_CONTINENT -> AFRICA

### 4.2 DEVISE ET MONNAIE

- USES_CURRENCY
- BELONGS_TO_MONETARY_ZONE
- USES_REFERENCE_CURRENCY
- USES_CENTRAL_BANK

EXEMPLE UEMOA :

SENEGAL
- USES_CURRENCY -> XOF
- BELONGS_TO_MONETARY_ZONE -> UEMOA
- USES_CENTRAL_BANK -> BCEAO

EXEMPLE CEMAC :

CAMEROUN
- USES_CURRENCY -> XAF
- BELONGS_TO_MONETARY_ZONE -> CEMAC
- USES_CENTRAL_BANK -> BEAC

### 4.3 MARCHE

- USES_NATIONAL_EXCHANGE
- USES_COMMON_EXCHANGE
- USES_MARKET_SCOPE

EXEMPLE UEMOA :

COTE_D_IVOIRE
- USES_COMMON_EXCHANGE -> BRVM
- USES_MARKET_SCOPE -> UEMOA

EXEMPLE CEMAC :

GABON
- USES_COMMON_EXCHANGE -> BVMAC
- USES_MARKET_SCOPE -> CEMAC

EXEMPLE MARCHE NATIONAL :

MAROC
- USES_MARKET_SCOPE -> MAROC

## 5. ROLE DU MARKET_SCOPE

MARKET_SCOPE DETERMINE LE NIVEAU AUQUEL UNE DONNEE DE MARCHE DOIT ETRE RECHERCHEE ET STOCKEE.

### MARCHE NATIONAL

MAROC
- MARKET_SCOPE = MAROC

NIGERIA
- MARKET_SCOPE = NIGERIA

### MARCHE COMMUN

BENIN
- MARKET_SCOPE = UEMOA

SENEGAL
- MARKET_SCOPE = UEMOA

CAMEROUN
- MARKET_SCOPE = CEMAC

TCHAD
- MARKET_SCOPE = CEMAC

## 6. CONSEQUENCE POUR LES INDICATEURS

### 6.1 ACTIONS

POUR UN PAYS UEMOA, L INDICE DE MARCHE ACTIONS PEUT ETRE PORTE PAR BRVM OU UEMOA.

EXEMPLE :

ACTIONS COTE_D_IVOIRE
- INDICE MARCHE PRINCIPAL -> INDICE ACTIONS UEMOA OU BRVM
- INDICE MARCHE SECONDAIRE -> AUTRE INDICE BRVM APPROUVE
- WTI - ACTIONS COTE_D_IVOIRE -> CALCULE AVEC LES FONDS ACTIONS DE COTE_D_IVOIRE
- WTI BENCH - ACTIONS COTE_D_IVOIRE -> METHODOLOGIE INDEPENDANTE UTILISANT LE MARCHE COMMUN

### 6.2 MONETAIRE

POUR LES PAYS UEMOA :

- TAUX DIRECTEUR -> BCEAO
- TAUX INTERBANCAIRE -> BCEAO OU SOURCE REGIONALE APPROUVEE
- INDICE MARCHE MONETAIRE -> UEMOA

POUR LES PAYS CEMAC :

- TAUX DIRECTEUR -> BEAC
- TAUX INTERBANCAIRE -> BEAC OU SOURCE REGIONALE APPROUVEE
- INDICE MARCHE MONETAIRE -> CEMAC

### 6.3 OBLIGATIONS

LES COURBES ET TITRES PEUVENT ETRE PORTES PAR :

- LE PAYS ;
- LA ZONE MONETAIRE ;
- UNE AGENCE REGIONALE DE TITRES ;
- UNE BANQUE CENTRALE ;
- UNE BOURSE OU UN MARCHE SECONDAIRE.

LE LIEN ENTRE LA CATEGORIE DU FONDS ET LA SERIE DE MARCHE DOIT ETRE EXPLICITE.

## 7. CONSEQUENCE POUR LA TAXONOMIE

LE FONDS CONSERVE :

- SON PAYS ;
- SA REGION ;
- AFRICA ;
- SA CLASSE D ACTIFS ;
- SA SOUS CLASSE D ACTIFS.

LE MOTEUR GENERE ENSUITE :

- CATEGORIE NATIONALE ;
- SOUS CATEGORIE NATIONALE ;
- CATEGORIE REGIONALE ;
- SOUS CATEGORIE REGIONALE ;
- CATEGORIE AFRICA ;
- SOUS CATEGORIE AFRICA.

LE MARKET_SCOPE N EFFACE AUCUNE DE CES CATEGORIES. IL DETERMINE UNIQUEMENT LA SOURCE ET LE PERIMETRE DES SERIES DE MARCHE COMMUNES.

## 8. CARDINALITES

- COUNTRY N -> 1 REGION
- REGION N -> 1 CONTINENT
- COUNTRY N -> 1 PRIMARY CURRENCY A UNE DATE DONNEE
- COUNTRY N -> 0..1 PRIMARY MONETARY ZONE A UNE DATE DONNEE
- COUNTRY N -> 0..1 COMMON EXCHANGE A UNE DATE DONNEE
- COUNTRY N -> 1 MARKET_SCOPE A UNE DATE DONNEE
- COUNTRY N -> 1 PRIMARY CENTRAL BANK A UNE DATE DONNEE

## 9. HISTORISATION

CHAQUE RELATION DOIT CONTENIR :

- RELATIONSHIP_ID
- SOURCE_ENTITY_ID
- RELATIONSHIP_TYPE
- TARGET_ENTITY_ID
- VALID_FROM
- VALID_TO
- IS_PRIMARY
- SOURCE_ID
- VALIDATION_STATUS
- CREATED_AT
- UPDATED_AT

AUCUNE RELATION HISTORIQUE NE DOIT ETRE ECRASEE.

## 10. PROCHAINE UTILISATION

CE MODELE SERVIRA A PRODUIRE :

1. LE REFERENTIEL EXPLICITE DES RELATIONS POUR LES 54 PAYS ;
2. LE CATALOGUE DES INSTITUTIONS PAR PAYS OU ZONE ;
3. LE CATALOGUE DES INDICATEURS ;
4. LA MATRICE PAYS OU ZONE X INDICATEUR X SOURCE ;
5. LE MOTEUR DE GENERATION DES CATEGORIES ;
6. LE MOTEUR D AFFECTATION DES BLOCS D INDICES.
