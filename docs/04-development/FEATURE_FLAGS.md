# Feature flags

```text
STATUS: CONDITIONAL_NOT_ACTIVE
```

Toute future feature flag doit avoir propriétaire, valeur par défaut sûre, périmètre, date d’expiration, métrique, rollback et procédure de suppression. Une flag ne remplace pas une migration ou une décision de qualité. Aucun système de feature flags n’est actif ou créé par cette documentation.
