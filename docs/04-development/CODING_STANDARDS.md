# Standards de code

Code lisible, typé lorsque possible, déterministe, testable et sans secrets. Conserver les erreurs explicites, l’idempotence, les dates et la provenance. Les scripts ne doivent pas inventer de valeur, convertir `NULL` en zéro ou écraser l’historique. Les changements de schéma suivent le manifeste gouverné et une migration forward.
