# Politique de pull requests

Une PR décrit objectif, limites, éléments structuraux, éléments testés, migrations, risques, preuves, blockers et prochaine action. Elle reste draft tant que les gates ne sont pas remplies. Toute modification de base, fusion, fermeture, reviewer ou commentaire nécessite une autorisation explicite dans la mission concernée. PR nº 1 et nº 2 restent inchangées par OF-DOC-003.
