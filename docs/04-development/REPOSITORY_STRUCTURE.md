# Structure du dépôt

Les racines documentaires gouvernent le projet ; `docs/00_PROJECT/` conserve audits et handoffs ; `data/` les référentiels ; `schemas/` les modèles SQL ; `migrations/` l’ordre gouverné ; `collectors/`, `loaders/` et `pipelines/` l’ingestion ; `tests/` les preuves ; `.github/workflows/` la CI. Les nouveaux dossiers `docs/01-governance` à `docs/12-optional` organisent le standard sans déplacer les canoniques historiques.
