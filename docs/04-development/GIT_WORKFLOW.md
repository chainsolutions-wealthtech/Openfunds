# Workflow Git

1. lire les points d’entrée ; 2. résoudre HEAD, base, merge-base et PR ; 3. identifier la tâche ; 4. définir allowlist et tests ; 5. effectuer un petit changement ; 6. vérifier le diff ; 7. committer atomiquement ; 8. pousser en fast-forward ; 9. contrôler CI et handoff. Aucun merge, rebase ou retargeting n’est implicite.
