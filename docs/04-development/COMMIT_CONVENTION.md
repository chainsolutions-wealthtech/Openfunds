# Convention de commits

Format recommandé : `type(scope): action [OF-ID]`. Types : `docs`, `feat`, `fix`, `refactor`, `test`, `chore`. Un commit est atomique, possède un parent vérifié, ne mélange pas documentation et technique sans justification et conserve un message factuel. Les commits de la boucle OF-DOC-003 sont documentaires et fast-forward uniquement.
