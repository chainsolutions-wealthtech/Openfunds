# Revue de code

La revue vérifie objectif, diff, contrats, migrations, sécurité, qualité des données, tests, documentation, rollback et absence de statut exagéré. Le reviewer distingue preuve exécutée et affirmation. Les fichiers générés sont comparés à leur source d’authoring. Une PR volumineuse nécessite une matrice de périmètre et des gates explicites.
