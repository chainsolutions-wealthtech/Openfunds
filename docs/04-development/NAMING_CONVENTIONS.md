# Conventions de nommage

Codes canoniques : majuscules, ASCII, underscore et stabilité historique. UUID pour les clés techniques ; identifiants fournisseurs séparés. Les noms humains, anciens noms et alias sont historisés. Les tâches suivent `OF-DOMAIN-NNN`; les boucles `OF-LOOP-*`. Les fichiers datés utilisent `YYYYMMDD` lorsque le dépôt suit cette convention.
