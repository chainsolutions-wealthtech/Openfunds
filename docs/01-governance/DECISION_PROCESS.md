
## Finalité

Définir quand et comment une décision doit être formalisée. Le registre canonique reste `DECISIONS.md`.

## ADR obligatoire lorsque

- l’architecture change ;
- un contrat ou schéma change ;
- une technologie structurante change ;
- une règle métier ou de calcul change ;
- une exception de sécurité ou de qualité est demandée ;
- une migration importante est décidée.

## Statuts

Proposée, Acceptée, Rejetée, Remplacée, Obsolète.

## Règle

Toute décision relie le contexte, les options, la décision, les conséquences, les preuves, la tâche `OF-*` et la date de revue.
