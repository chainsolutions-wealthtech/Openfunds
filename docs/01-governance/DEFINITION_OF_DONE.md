# Definition of Done
```text
STATUS: ACTIVE
TIER: BUILD
INTEGRATION_ACTION: CREATE_CANONICAL
TASK_ID: OF-DOC-003
LAST_VERIFIED: 2026-08-05
```

## Finalité

Définir quand une tâche est réellement terminée.

- [ ] Code ou livrable terminé
- [ ] Tests applicables réellement réussis
- [ ] Auto-revue effectuée
- [ ] Revue obtenue lorsque requise
- [ ] Documentation mise à jour
- [ ] Migration et rollback vérifiés lorsqu’applicables
- [ ] CI vérifiée sans extrapolation
- [ ] État de boucle mis à jour
- [ ] Prochaine action ou clôture explicite
- [ ] Aucun statut supérieur aux preuves

Pour Openfunds, `IMPLEMENTED` ne vaut jamais `VERIFIED_COMPLETE` sans les gates correspondants.
