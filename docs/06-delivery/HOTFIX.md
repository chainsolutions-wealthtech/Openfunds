# Hotfix

```text
STATUS: CONDITIONAL_NOT_ACTIVE
```

Un hotfix exige incident identifié, portée minimale, test de reproduction, approbation, rollback, preuve après correction et réintégration dans la ligne normale. L’urgence n’autorise ni force-push, ni suppression historique, ni contournement silencieux de checksum. Aucune procédure hotfix n’est activée ici.
