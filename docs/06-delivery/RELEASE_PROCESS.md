# Processus de release

Proposer version et contenu, vérifier Definition of Ready, figer le périmètre, exécuter tests et migrations, obtenir revue, produire changelog et artefacts, promouvoir par environnement, valider et handoff. Une release échoue si un blocker critique, un secret ou un statut non prouvé subsiste. OF-DOC-003 ne crée aucune release.
