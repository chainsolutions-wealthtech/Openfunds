# Rollback

```text
STATUS: CONDITIONAL_NOT_ACTIVE
```

Tout changement risqué définit signal de déclenchement, responsable, sauvegarde, commande ou migration corrective, vérification et communication. Les migrations sont forward-only : rollback métier par migration compensatrice, jamais par modification d’un fichier appliqué. Aucun rollback production n’est exécuté ici.
