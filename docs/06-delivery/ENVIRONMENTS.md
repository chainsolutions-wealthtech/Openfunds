# Environnements

Environnements observés : GitHub Actions éphémère et PostgreSQL 16 de test. PostgreSQL persistant, stockage objet et production restent non configurés. Pour chaque futur environnement, consigner URL non secrète, rôle, propriétaire, branche/version, secrets requis, données autorisées, migrations, sauvegarde et monitoring. Ne jamais committer les identifiants.
