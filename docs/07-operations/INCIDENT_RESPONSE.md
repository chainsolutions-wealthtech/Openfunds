# Réponse aux incidents

```text
STATUS: CONDITIONAL_NOT_ACTIVE
```

Détecter, qualifier, contenir, préserver les preuves, corriger, valider, communiquer et produire un postmortem. Un incident de données conserve les valeurs et sources contradictoires. Un secret exposé est révoqué immédiatement. Les propriétaires et canaux opérationnels sont à définir avant activation.
