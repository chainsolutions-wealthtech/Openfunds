# Checklist de revue sécurité

- [ ] secrets absents du diff et des logs
- [ ] permissions minimales
- [ ] entrées validées et sorties protégées
- [ ] dépendances et licences vérifiées
- [ ] SQL et migrations évalués
- [ ] données sensibles classifiées
- [ ] audit, alertes et rollback définis
- [ ] menaces et abus documentés
- [ ] aucun environnement production modifié sans autorisation
