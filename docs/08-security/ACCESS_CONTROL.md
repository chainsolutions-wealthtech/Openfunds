# Contrôle d’accès

Appliquer moindre privilège, séparation lecture/écriture/admin, comptes nominatifs, revue périodique et révocation rapide. Les secrets de CI et bases ne sont jamais versionnés. Toute future API ou base définit rôles, périmètres, journalisation et tests d’autorisation. Les accès actuels et propriétaires nominatifs restent à définir.
