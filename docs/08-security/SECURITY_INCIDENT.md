# Incident de sécurité

```text
STATUS: CONDITIONAL_NOT_ACTIVE
```

Arrêter l’action, préserver les preuves, révoquer les secrets concernés, contenir l’accès, qualifier l’impact, notifier les responsables et documenter la correction. Ne jamais committer une preuve contenant le secret. Le propriétaire et les contacts d’escalade sont à définir avant activation formelle.
