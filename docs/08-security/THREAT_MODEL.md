# Modèle de menace

```text
STATUS: CONDITIONAL_NOT_ACTIVE
```

Actifs : données canoniques, artefacts bruts, secrets, migrations, CI et identités. Menaces : altération de source, injection, exfiltration, dépendance compromise, confusion de statut, migration destructive et accès excessif. Pour chaque menace, consigner acteur, scénario, détection, contrôle, risque résiduel et test. Modèle détaillé à définir.
