# Index des ADR

Le registre canonique historique est `../../DECISIONS.md`. Les ADR détaillés existants se trouvent aussi sous `../01_ARCHITECTURE/`. Utiliser `ADR-0000-template.md` pour une nouvelle décision, rechercher toute collision d’identifiant et mettre à jour DECISIONS, TODO, SUIVI et CHANGELOG. Ce dossier n’efface ni ne renumérote les décisions existantes.
