# Glossaire

| Terme | Définition |
|---|---|
| Canonique | représentation faisant autorité après validation |
| Authoring | surface gouvernée dans laquelle une référence est modifiée |
| Runtime | état effectivement appliqué dans PostgreSQL |
| Raw artifact | source originale immuable, hashée |
| Observation | valeur publiée ou directement extraite |
| Calculated observation | valeur dérivée avec formule et version |
| Fund/SubFund/ShareClass | niveaux économiques/juridiques à stabiliser |
| WTI | performance agrégée des fonds éligibles |
| WTI Bench | benchmark indépendant du WTI |
| RFR | référence de taux sans risque |
| MAR | rendement minimum acceptable |
| Loop | intervention bornée avec preuves et handoff |
| Gate | condition nécessaire avant la phase suivante |
