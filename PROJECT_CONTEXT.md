# Contexte du projet Openfunds

Openfunds construit un référentiel canonique panafricain de fonds et de données
financières. Le dépôt courant est une fondation d’architecture, de gouvernance,
de référentiels, de collecte FX et de classification déterministe.

## Contexte Git

Branche de travail : `architecture/africafunds-country-indicators-v0.1`. Baseline documentaire : `59f6475102b8a0c5b1274060afc412db787f2caf`.
Le HEAD doit toujours être résolu dynamiquement. `main` reste minimale et n’est
pas une cible d’écriture directe.

## Contexte métier

Le modèle doit conserver identité, noms, alias, Fund/SubFund/ShareClass,
organisations, documents, événements, NAV/AUM/dividendes, sources, provenance,
validité métier, corrections et calculs versionnés.

## Limites

Aucun historique complet, aucune production persistante, aucun WTI actif, aucun
mapping openfunds complet et aucun modèle fonds final validé.
