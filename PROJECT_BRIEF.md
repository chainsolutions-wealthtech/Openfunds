# Fiche synthétique Openfunds

## Problème

Les données africaines de fonds, marchés et institutions sont dispersées,
hétérogènes, peu historisées et rarement traçables jusqu’à leur preuve.

## Solution

Un modèle canonique interne, PostgreSQL comme vérité runtime, openfunds comme
couche d’échange, une provenance complète et une documentation gouvernée par
boucles vérifiables.

## Public

Data engineers, analystes, sociétés de gestion, distributeurs, régulateurs,
applications AfricaFunds/ChainSolutions et assistants IA.

## État

Architecture et pilotes FX avancés ; historique durable, modèle fonds final,
mapping openfunds, API et produits analytiques encore incomplets.
