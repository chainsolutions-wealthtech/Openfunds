# Sécurité

## Secrets

Aucun mot de passe, token, URL de base avec identifiants, clé privée ou artefact
confidentiel ne doit être commité. Utiliser les secrets GitHub et variables
d’environnement documentées.

## Données

Conserver la provenance, appliquer le moindre privilège, distinguer recherche,
donnée canonique et production. Ne jamais publier de données personnelles ou
réglementées sans classification et base légale.

## Incidents

Arrêter l’écriture, révoquer le secret, conserver les preuves nettoyées, ouvrir
un incident autorisé et documenter correction, rotation et prévention.
